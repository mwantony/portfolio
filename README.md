# 🚀 Portfolio - Antony Maziero Warken

## Estrutura do Projeto

```
portfolio/
├── index.html
├── vite.config.js
├── public/favicon.svg
└── src/
    ├── main.jsx
    ├── App.jsx
    ├── index.css
    ├── context/
    │   ├── ThemeContext.jsx
    │   └── LanguageContext.jsx
    ├── hooks/
    │   └── useIpLocation.js
    ├── locales/
    │   ├── pt.json
    │   └── en.json
    └── components/
        ├── Navbar.jsx
        ├── Hero.jsx
        ├── About.jsx
        ├── Projects.jsx
        ├── Resume.jsx
        ├── Contact.jsx
        └── Footer.jsx
```

## Como rodar

```bash
npm install
npm run dev
```

## Personalização

- **WhatsApp**: em `Contact.jsx`, substitua `55XXXXXXXXXXX`
- **Projetos**: edite os arrays em `src/locales/pt.json` e `en.json`
